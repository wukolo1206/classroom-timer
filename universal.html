    🛠 下載原始碼自己修改
    
        
    整個工具就是一個 HTML 檔，不用安裝。下載後可以自己改，或把檔案交給 AI 說明想改什麼。目前版本：
    
        
      
            
    1. 先按「💾 備份與還原 → 下載完整備份」，保存這裡的資料。
      2. 
            
    2. 按下方「下載原始碼」，得到 班級工具箱.html。
      3. 
            
    3. 用記事本或 VS Code 打開修改，存檔時用 UTF-8 編碼。
      4. 
            
    4. 存檔後雙擊檔案，用瀏覽器打開。第一次打開是空白的（自己電腦上的檔案和這個網址各存各的資料），請到「💾 備份與還原」還原步驟 1 的備份。
      5. 
        
    
        
    
            常改的地方：在檔案中搜尋 【可自行修改】，有學期開學日與週數、預設秩序項目、含氟表單標題、備份提醒天數。
        
    
        
      
            
    • 標示 【請勿直接修改】 的 SH150 區塊有特殊跳脫字元，改錯會讓 SH150 分頁打不開。
      • 
            
    • 讀寫資料請用 ctuStore，它會自動加上 ctu_ 前綴；不要直接寫 localStorage，以免蓋掉 SH150 等其他工具的資料。
      • 
            
    • 自己的版本不會收到這裡之後的更新；想要新功能，可以重新下載一份再改。
      • 
            
    • 打開時需要網路（版面樣式從網路載入）。改壞了就重新下載一份，資料用備份還原。
