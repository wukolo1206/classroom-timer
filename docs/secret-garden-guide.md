# 班級祕密花園使用說明

目前為本機候選版本，正式網址尚未更新。

1. 從班級計時器的「音量計」按「開啟班級祕密花園」，保留原頁面開啟。
2. 確認下方顯示夥伴已更新，選活動、時間及「安靜自習／輕聲討論」。
3. 按「開始照顧花園」，允許麥克風。成功開始後才倒數。
4. 合宜音量累積15秒，第一位夥伴出現；後續依活動長度與全班人數分配。全程合宜音量時，全班會在活動結束前到齊。
5. 短暫聲響不會讓夥伴消失；持續超過目標3秒，夥伴休息、花園暫停成長。恢復到目標下方2秒後繼續。
6. 老師講解時按右上「Ⅱ」；倒數和麥克風一起暫停，按「▶」繼續。切離花園也會自動暫停。
7. 學生已在計分系統換角後，按「更新夥伴」套用最新角色，倒數與已到場名單保留。完成同步的換角／復原才會反映在正式雲端頭像。
8. 時間到自動關閉麥克風，收藏成果；「我的花園收藏」顯示這台瀏覽器最近12次的摘要。

圖中的角色直接沿用計分原圖，同款角色以座號區分。每位同學每場最多出現一次，跨場輪替出場起點；順序與個人點數或表現無關。

若花園一直沒有成長，先確認麥克風有收到聲音，再展開「音量微調與使用說明」提高目標。顯示的設定值是麥克風約略音量，不能當作正式噪音檢測。

「示範模式」使用明確標示的模擬配對，不代表真實學生目前的角色。首次直接開花園且未載入班級時，可以用示範看看；要使用正式配對，請重新由原班級頁面開啟。

正式版頭像更新需要同時發布靜態頁面與GAS唯讀接口；發布前，舊正式頁面不會有新花園入口。花園只讀座號與頭像，不錄音、不上傳聲音，也不會自動加扣學生點數。
