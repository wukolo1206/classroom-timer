# 班級祕密花園使用說明

已於2026-11-05發布：GAS @65／全校版v1.23。

1. 從班級計時器「音量計」開啟花園，保留原班級頁面以讀取最新角色；首次直接開啟也可選明確標示的示範夥伴。
2. 選「直接偵測・不限時」或「活動倒數」。直接偵測顯示已偵測多久，由老師手動結束；活動倒數到時自動結束。
3. 選自習／輕聲討論，調整三個秒數：合宜音量累積幾秒迎一位、連續超標幾秒休息一位、全員後幾秒升級。預設15／8／30秒。
4. 按開始並允許麥克風。投影左上顯示約略分貝、目標線及音量狀態；右上顯示下一位夥伴或下一次升級倒數。
5. 音量合宜，小倒數前進；超標立即暫停並變色提示。短暫聲響不會直接減少夥伴；持續超標達設定秒數才休息一位，繼續超標每隔同樣秒數再減一位。
6. 恢復合宜音量後接著倒數；從不在場的同學隨機迎接，包含先前去休息的夥伴。不重複顯示同一位，順序不依座號或點數。
7. 全員到齊後依序解鎖花朵盛開、蝴蝶來訪、星光花園，再繼續累積祝福星。超標暫停升級；若夥伴離開，先迎回夥伴再累積這次尚未完成的升級；已解鎖景色保留。
8. 夥伴會搖擺、小跳、轉身或漂浮，超標與老師暫停時休息；系統的減少動畫偏好有效。
9. 老師講解按右上Ⅱ，計時與麥克風一起暫停；回來按▶繼續。切到其他視窗也會自動暫停。
10. 學生在計分系統換角並完成同步後，按更新夥伴套用；保留活動進度。時間到或手動結束會關閉麥克風並收藏成果。

想快速試看升級，可先設「出場1秒、升級5秒」。正式活動再調回適當速度。

頭像直接沿用原計分造型，同款加座號區分。花園的退場代表全班合作狀態，不判定個人表現，也不影響正式點數。

音量數字為麥克風約略值，可在音量微調提高／降低目標，不能當正式噪音檢測。只在本機計算，不錄音、不上傳聲音；正式頭像投影只含座號與角色。原班級頁面關閉時無法讀取最新雲端頭像，會保留上次快照並顯示更新失敗。

收藏保存在這台瀏覽器，最多最近12次。正式花園與GAS唯讀頭像連動均已發布。請重整原班級頁面，從音量計開啟花園，才能載入目前雲端頭像。
