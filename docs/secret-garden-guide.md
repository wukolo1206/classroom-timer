# 班級祕密花園使用說明

已於2026-11-06發布：全校版v1.28，GAS仍@65；本版加入月光後持續新發現。

1. 從班級計時器「音量計」開啟花園，保留原班級頁面以讀取最新角色；首次直接開啟也可選明確標示的示範夥伴。
2. 選「直接偵測・不限時」或「活動倒數」。直接偵測顯示已偵測多久，由老師手動結束；活動倒數到時自動結束。
3. 選自習／輕聲討論，調整三個秒數：合宜音量累積幾秒迎一位、連續超標幾秒休息一位、全員後幾秒升級。預設15／8／30秒。
4. 按開始並允許麥克風。投影左上顯示約略分貝、目標線及音量狀態；右上顯示下一位夥伴或下一次升級倒數。
5. 音量合宜，小倒數前進；超標立即暫停並變色提示。短暫聲響不會直接減少夥伴；持續超標達設定秒數才休息一位，繼續超標每隔同樣秒數再減一位。
6. 恢復合宜音量後接著倒數；從不在場的同學隨機迎接，包含先前去休息的夥伴。不重複顯示同一位，順序不依座號或點數。
7. 全員到齊後從夥伴入園開始，依序解鎖花圃甦醒、綠意成蔭、蝴蝶來訪、池塘映光、祕密花園木橋、晚霞時光、月光成畫，之後每段合宜音量獲得一次「花園新發現」。超標暫停升級；若夥伴離開，先迎回夥伴再累積這次尚未完成的升級；已解鎖景色保留。
8. 夥伴會在自己的附近散步，再輪替看花、野餐、澆水、追蝴蝶或閱讀，有對應道具。超標、老師暫停或沒有麥克風訊號時休息；系統的減少動畫偏好有效。
9. 老師講解按右上Ⅱ，計時與麥克風一起暫停；回來按▶繼續。切到其他視窗也會自動暫停。
10. 學生在計分系統換角並完成同步後，按更新夥伴套用；保留活動進度。時間到或手動結束會關閉麥克風並留下活動摘要。結束後保留當下畫面；更新頭像於下一場重新讀取。

想快速試看升級，可先設「出場1秒、升級5秒」。正式活動再調回適當速度。

頭像直接沿用原計分造型，同款加座號區分。花園的退場代表全班合作狀態，不判定個人表現，也不影響正式點數。

音量數字為麥克風約略值，可在音量微調提高／降低目標，不能當正式噪音檢測。只在本機計算，不錄音、不上傳聲音；正式頭像投影只含座號與角色。原班級頁面關閉時無法讀取最新雲端頭像，會保留上次快照並顯示更新失敗。

活動紀錄只保存摘要與頭像，最多最近12次。想保留整幅畫，可在活動中或結束後按「保存花園畫（PNG）」，預設不含座號、音量尺與倒數，也可勾選包含座號。圖片下載到裝置，不存進瀏覽器收藏；開始新活動／重新整理或關閉後，舊摘要不能重建原圖。下載失敗可在離開前重試。正式花園與GAS唯讀頭像連動均已發布。請重整原班級頁面，從音量計開啟花園，才能載入目前雲端頭像。

入口會明確標示來源：看到「已載入31位班級夥伴」可直接開始；看到「上次」代表保存的快照；「只試玩（使用模擬角色）」只在尚未載入班級時提供。直接開花園不會自動取得私有班級資料，請從原班級頁面的音量計開啟。

花朵會隨合宜音量逐株增加，從嫩芽、花苞慢慢綻放；迎接時最多8株嫩芽／花苞；解鎖花圃後每6秒逐株增加，最多48株，另有4片花圃各3朵。晚霞停止新增株數，原有花苞仍可開花。全員到齊後的第一次升級另解鎖4片盛開花圃。

31位以預設15秒出場、30秒升級，最短需要11分15秒；若10分鐘內想完成，可手動調成10秒出場（最短8分40秒）。時間到只完成一部分也能保存今日花園。

## 月光後的花園日常

- 第1次新發現固定出現小噴水池與籃球活動。第2～8次依序解鎖足球、排球、網球、棒球、羽球、播種、移苗種花；原來看花、野餐、澆水、追蝶和閱讀繼續輪替。
- 每次最多2位隨機夥伴展示新活動8秒合宜音量時間，展示對象不代表個人表現或誰發出聲音。小螢幕以抱球／持物呈現，避免擋到別人與座號。
- 第1、5、9……次新發現更換主景，木橋池塘／噴水池／兔子石像／小鳥飲水台／花藤拱門／小風車會輪替；一輪看過再重複，不會一直堆更多建築。道具另有配色變化。
- 主景換景、球類與園藝動作一樣遵守超標／無訊號／老師暫停；夥伴退場只歸零尚未完成的倒數，已有次數與解鎖內容保留。新活動則重新從前8階段開始。
- 保存PNG包含當下主景與道具。新活動紀錄會標示新發現次數與主景；舊版本的祝福紀錄不會改成新發現。
