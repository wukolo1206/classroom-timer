# SH150 每週填報學校表單：使用說明

適用：班級工具箱（全校通用版）v1.7 起的「🏃 SH150 運動登記」分頁。

---

## 給老師：每週怎麼填報

1. 在 SH150 分頁選好要填報的**第幾週**。
2. 按「📤 填報學校本週資料」，畫面會列出：
   - 班級、導師、學期與週次、週一～週五的日期
   - 每天的學生跑步、跳繩下數、跳繩換算圈數、導師跑步
   - **學生填報圈數**（跑步＋跳繩換算）與**導師填報圈數（尚未乘 2）**
3. 核對數字。黃色框是提醒，例如名冊外的座號有紀錄、這週沒有紀錄、還沒核對過欄位。有提醒時要先勾選「我已核對」才能開啟表單。
4. 按「🚀 開啟預填表單」，學校的 Google 表單會在新分頁打開，導師、班級、兩個圈數已經填好。
5. 在 Google 表單：
   - 用**學校帳號**登入
   - **填報日期時間**請自己填（目前不會自動帶入）
   - 補上 **1～2 張活動照片**
   - 再核對一次數字，**自己按「提交」**

> 開啟表單不代表已繳交。工具看不到學校有沒有收到，只有你在 Google 表單按「提交」才算完成。

### 計算方式

- 跳繩：**每天全班加總後**，每 200 下換算 1 圈，五天再相加（和 SH150 列印表的算法相同）。
- 導師：填**原始圈數**，學校後台會自動乘 2，工具不會先乘。
- 導師若另有跳繩，在「導師額外換算圈數」填**尚未乘 2** 的換算圈數。這個數字只用在這一次填報，不會存進紀錄，也不會改到 SH150 的列印總數。
- 不含體育課：工具無法分辨哪些紀錄是體育課，請確認登記的內容符合學校規定。

### 打不開預填表單時

- **按鈕是灰色的**：看紅色框的原因。常見的有：
  - 班級名稱不是表單上的選項（例如還是 `4XX`），到「🏫 班級設定」改成 `401` 這種格式
  - 導師姓名還是 `OOO 老師`，請改成真實姓名
- **新分頁沒有出現**：按畫面上的「點這裡再次開啟」。
- **表單沒有帶入數字，或學校換了表單**：按「📋 複製填報資料」，對照文字自己填。可以按「開啟空白表單」。
- **複製沒反應**：畫面會出現文字框，按「全選」後按 Ctrl+C。

### 第一次使用：核對欄位

第一次開啟表單時，請確認導師、班級、學生圈數、導師圈數都填在正確的格子裡。確認無誤後，回到工具按「表單上四個欄位都帶入正確（記錄為已核對）」，之後這台電腦就不會再提醒。這只代表你核對過格子位置，不代表學校已收到資料。

## 給維護者：學校換表單時

設定位置：「📤 填報學校本週資料 → ⚙️ 學校表單設定」。設定只存在 `ctu_school_form_config`，修改、重設都**不會動到任何運動紀錄或班級資料**。

### 取得預填範本（請承辦協助）

1. 在表單**編輯畫面**按「更多（⋮）→ 預先填寫表單」。
2. 填示範答案，方便辨認欄位：
   - 導師：示範導師
   - 班級：任一合法選項（例如 101）
   - 學生圈數：`123456`
   - 導師圈數：`654321`
   - 日期時間：任一示範值
3. 按「取得連結」並複製。這一步不會產生正式回應，也不用上傳照片。

### 套用到工具

1. 在「更換學校表單」貼上連結，按「解析連結」。
2. 依每一列右邊的示範答案，選擇它代表導師姓名、班級、學生當週總圈數，還是導師當週總圈數。範例答案不會被保存。
3. 按「儲存新設定」。核對狀態會變成「尚未核對」，第一次開啟時請重新核對。
4. 要分給其他老師：按「⬇️ 匯出填報設定」，對方按「⬆️ 匯入填報設定」。設定檔只有表單網址和欄位對應，不含名冊或紀錄。

### 填報日期時間

目前**不自動帶入**，請老師在表單手動填寫。日期欄位的網址參數格式還沒有用官方範本實測（午夜 00:05、下午 13:05、跨年都要測）。實測正確後，可以在解析範本時把日期欄位選成「填報日期－年／月／日／時／分」，再勾選「日期欄位已用官方預填範本實測」。

### 不同情況怎麼處理

| 學校表單的變更 | 工具要做什麼 |
|---|---|
| 只改說明、標題、題目順序 | 通常不用改，開啟時人工核對 |
| 題目刪掉重建 | 重新貼範本、重新對應 |
| 換全新表單 | 貼新表單的範本、重新對應 |
| 新增必填題 | 老師在表單手動補填 |
| 改班級選項 | 「進階：班級選項」更新成和下拉選單完全相同 |
| 改計算規則 | 不是改網址就能處理，需要另外修改程式並驗收 |
| 停收、改權限 | 由學校處理；老師可先用複製備援 |

### 限制

- 只接受 `docs.google.com` 的作答者網址（`/viewform`）；`forms.gle` 短網址要先打開，再複製完整網址。
- 工具不能代替登入、不能上傳照片、不能代為提交，也無法確認學校是否收到。
- 預填連結含導師姓名、班級與圈數，會留在瀏覽器歷史紀錄；不含學生姓名與照片。
