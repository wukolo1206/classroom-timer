## 1. 目標與範圍

做一個全校老師都能直接開來用的班級工具。每班老師自己設定名冊與項目，資料只存在自己教室大屏的瀏覽器。

- **新網址**：`https://wukolo1206.github.io/classroom-timer/universal.html`
- **新檔案**：repo 根目錄 `universal.html`，單檔 HTML + Tailwind CDN + 原生 JS，延續現有技術
- **不需要**：登入、試算表、GAS、離線快取（教室有網路即可）

### 絕對不能影響的三個既有東西

| 既有網址／檔案 | 目前使用者 | 本案的處理 |
|---|---|---|
| `classroom-timer/index.html` 與 `gas/index.html`（408 GAS @22） | 408 班、大屏書籤 | **完全不修改**，也不部署 GAS |
| `sh150-tracker/universal.html` | 已分享給其他老師 | **不修改 sh150-tracker repo**；新版只會**讀取**它的本機資料，不會寫入 |
| `classroom-timer/`（GitHub Pages 本機模式） | 可能有人在用 | 新版不讀寫它的 localStorage key |

## 4. 共用班級設定

照 SH150 通用版的設定視窗與欄位，五個分頁共用同一份設定：

| 欄位 | 說明 |
|---|---|
| 班級 | 例如 `4XX`，用於標題、列印與備份檔名 |
| 導師 | 列印表頭用 |
| 小隊長 | SH150 列印用 |
| 人數 | 沒有貼姓名時用這個值產生純座號名冊 |
| 姓名 | 一行一位，第 n 行就是 n 號；自動去掉前面的座號（沿用 SH150 規則 `^\d+[\s.、\t]+`）；空行代表空號 |

- 第一次開啟、還沒有班級設定時，自動跳出設定視窗
- 名冊只能從設定視窗修改，各分頁都讀這份，不再各自維護
- 秩序登記的**座位表**仍放在秩序登記分頁裡編輯（屬於該分頁的設定）。預設座位表依人數自動排成 6 欄，不帶 408 的雙桌配置

### 姓名遮罩

- 所有分頁的**畫面顯示**一律套用 SH150 的 `maskName`：兩字「王○」、三字以上「王○明」
- **列印版**（含氟繳交版、SH150 列印）顯示全名
- **複製報告／匯出 CSV** 預設用全名，因為是給老師自己看或交給學校的。⚠ 這點待使用者確認（見 §10）

## 5. 學期週次

SH150 和含氟紀錄都需要「第幾週」與每週日期。

- 程式頂端放一組常數，由維護者（使用者）**每學期更新一次並 push**：
  ```js
  var SEMESTER = { label: '115-1', startMonday: '2026-08-31', weeks: 22 };
  ```
- 每週日期由 `startMonday` 推算，取代 `index.html` 含氟紀錄裡寫死的 `days` 陣列
- 班級設定裡保留「手動調整」：老師可以覆寫開學日與週數，存在本機；清空即回到程式內建值
- 含氟紀錄目前是 20 週、SH150 是 22 週。⚠ 是否統一用 `SEMESTER.weeks`，待使用者確認（見 §10）

## 6. 本機儲存

### 6.1 key 命名

- 所有 key 一律加前綴 **`ctu_`**（classroom-timer universal）
- **同網域風險**：`wukolo1206.github.io` 底下的 `sh150-tracker`、`classroom-timer/index.html`、`universal.html` 共用同一個 localStorage。key 撞名會互相覆蓋，所以新版**絕不使用**下列既有 key：

| 已被占用 | 使用者 |
|---|---|
| `sh150_class_config`、`sh150_universal_all_records`、`sh150_records_*` | SH150 |
| `seatCheckItems`、`seatCheckRecords`、`seatLayout`、`seatSyncQueue`、`seatSummaryRange`、`timer*`、`clean*`、`examInfo`、`group*`、`weekly*` | classroom-timer 本機模式 |

### 6.2 新版 key 一覽（草案）

**實作：** 為了少改程式，主程式的 `localStorage` 全部換成 `ctuStore`，它會自動在原本的 key 名稱前加 `ctu_`（例如 `ctu_seatCheckRecords`、`ctu_timerTabOrder`、`ctu_weeklyRecordData`）。下表中只有 `ctu_class`、`ctu_semester_override`、`ctu_sh150_records`、`ctu_meta`、`ctu_timerTabHidden` 照原規劃命名；其他各分頁沿用原 key 名稱加前綴。

| key | 內容 |
|---|---|
| `ctu_class` | 班級設定（§4） |
| `ctu_semester_override` | 老師手動調整的開學日／週數（可為空） |
| `ctu_tabs` | 分頁順序與隱藏清單 |
| `ctu_timer` | 計時器自訂選項、歷史紀錄 |
| `ctu_seat_items`、`ctu_seat_layout`、`ctu_seat_records` | 秩序登記 |
| `ctu_weekly` | 含氟紀錄設定與每格狀態 |
| `ctu_group` | 小組討論設定、分數、抽籤紀錄 |
| `ctu_sh150` | SH150 各週紀錄（結構同 SH150 的 `allWeeksData`） |
| `ctu_meta` | 資料版本 `schema`、上次備份時間 `lastBackupAt`、SH150 匯入狀態 |

- 每個 key 的內容都是 JSON 物件，`ctu_meta.schema` 從 `1` 起算，日後改格式時用它做遷移
- 所有讀寫都包 try/catch，讀取失敗就回到預設值，頁面不能因此壞掉

## 7. SH150 舊資料帶入

**條件**：`ctu_meta` 沒有匯入紀錄，且 localStorage 裡有 `sh150_class_config` 或 `sh150_universal_all_records`。

**流程**：

1. 開啟時跳出提示：
   > 偵測到這台電腦有 SH150 運動登記的資料（班級 4XX，共 N 週紀錄）。
   > 要複製一份到新版嗎？
   > ・帶入後兩邊**各自獨立**：之後在新版登記的，舊 SH150 網址看不到，反之亦然。
   > ・舊 SH150 網址的資料**不會被改動**，仍可照常開啟。
   >
   > [帶入] [不要，從空白開始] [稍後再說]
2. **帶入**：
   - `sh150_class_config` → `ctu_class`（班級、導師、小隊長、人數、姓名）
   - 紀錄依 SH150 自己的讀取順序取得：`sh150_universal_all_records` → `sh150_records_{班級}` → `sh150_records_4XX` → `sh150_records_default`，寫入 `ctu_sh150`
   - 寫入 `ctu_meta.sh150Import = { at, result: 'imported' }`
3. **不要**：寫入 `result: 'declined'`，之後不再詢問；設定裡保留「從 SH150 帶入」按鈕，可以事後再帶
4. **稍後再說**：不寫任何東西，下次開啟再問
5. 全程**只呼叫 `getItem` 讀取 `sh150_*`**。程式碼裡不得出現任何對 `sh150_*` 的 `setItem`／`removeItem`（驗收時用 grep 檢查）

**限制**（提示文字或說明頁要寫）：只偵測得到同一台電腦、同一個瀏覽器的資料。其他裝置的 SH150 資料，請在 SH150 按「匯出」，再到新版設定按「匯入 SH150 備份檔」（格式為 SH150 的 `version: 2` 匯出檔）。

## 9. 備份與還原

- **一鍵完整備份**：把所有 `ctu_*` 合成一個 JSON 檔下載
  - 檔名：`班級工具_{班級}_{YYYYMMDD}.json`

  - 下載後更新 `ctu_meta.lastBackupAt`
- **還原**：選檔 → 檢查 `app` 與 `schema` → 顯示摘要（班級、紀錄筆數、備份時間）→ 確認後覆蓋
  - **覆蓋前自動下載一份目前資料的備份**（檔名加 `_還原前`）
- **定期提醒**：距離 `lastBackupAt` 超過 14 天（或從未備份但已有紀錄），就在畫面角落顯示小提醒「已 N 天沒有備份 [立即備份]」。不跳視窗，不擋操作
