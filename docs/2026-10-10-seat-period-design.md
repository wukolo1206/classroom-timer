## 1. 要做到什麼

1. 秩序登記**每一節課從 0 開始記**：座位表上看到的次數是「這一節」的，不再是整天累加。
2. 打開時**依作息自動跳到現在這一節**，也可以手動點別的節次（補登）。
3. 統計可以選看：**某一節／某一天全部節次／自訂日期範圍／只看某幾節**。
4. 舊紀錄（沒分節的）全部保留，歸在「未分節」，看得到、改得了。

## 2. 節次與作息

### 2.1 時段

| 代碼 | 試算表 H 欄文字 | 時間 |
|---|---|---|
| `m` | 早自習 | 07:40–08:40 |
| `1`～`4` | 第1節～第4節 | 08:40–09:20、09:30–10:10、10:30–11:10、11:20–12:00 |
| `n` | 午休 | 12:00–13:30 |
| `5`～`7` | 第5節～第7節 | 13:30–14:10、14:20–15:00、15:20–16:00 |
| （空） | （空白） | 未分節（舊紀錄） |

- 代碼與 H 欄文字**固定雙向對照**（`SEAT_PERIODS` 常數，兩版與後端同一份定義）。
- 作息時間是程式內常數（全校同一個學校、同一套鐘聲），標【可自行修改】；**不做畫面上的作息編輯**（原 v0.1 的「⚙️ 修改」取消），也就沒有雲端設定載入順序的問題。常數由測試檢查：時間遞增、不重疊、代碼不重複。
- 時間一律用使用者電腦的本地時間（台灣）。

### 2.2 自動／手動

- 有兩種狀態：**自動**（跟著時間走）與**手動**（老師點了某一節）。
- **自動**：每分鐘檢查一次，只有在「選的日期是今天」而且**沒有開著登記彈窗**時，才切到現在的節次；跨午夜時日期也跟著換到新的今天。判斷規則：每節從開始時間算到下一節開始（下課算剛結束那節）；07:40 前算早自習、16:00 後算第 7 節。
- **手動**：點任何節次按鈕（或看別天）就進入手動，不再自動跳。畫面顯示「手動・按這裡回到自動」。
- 回到自動的方式：按「回到自動」、切到別的分頁再切回來、或日期點回今天。

## 3. 資料格式與後端

### 3.1 時段鍵

```
'2026-10-10'      ← 未分節（舊紀錄，原樣保留）
'2026-10-10#3'    ← 第 3 節
'2026-10-10#m'    ← 早自習
```

- 本機 `seatCheckRecords` 的頂層鍵改為時段鍵，下層結構不變。
- **集中三個函式**處理，其他程式一律呼叫、不自行拆字串：`slotKey(date, period)`、`parseSlot(key) → { date, period }`、`slotDate(key)`。
- 畫面狀態分開存：`seatActiveDate`（日期）、`seatActivePeriod`（節次代碼或 `''`＝未分節）、`seatViewAll`（全天檢視）。寫入目標＝`slotKey(seatActiveDate, seatActivePeriod)`；全天檢視時**沒有寫入目標**。

### 3.2 試算表 H 欄

- 「上課表現紀錄」最後面新增 **H 欄「節次」**，A～G 不動。後端第一次讀寫時若 H1 是空白，補表頭「節次」（只寫這一格）。
- 一列＝日期＋座號＋項目＋節次。`setSeatCount(時段鍵, …)` 參數不變，後端用 `parseSlot` 拆開，比對 A＋B＋G＋H。
- 讀取時 H 欄文字經對照表轉代碼；**對照表以外的文字**保留成獨立時段（鍵 `日期#?原文`，畫面顯示原文），不併入未分節。

### 3.3 清除（範圍明確化）

| 操作 | 範圍 | 後端（新） |
|---|---|---|
| 清除本節 | 選定日期＋選定節次（含「未分節」），可限定座號 | `clearSeatSlot(opId, 時段鍵, 座號?)`：比對 A＋H（＋B） |
| 清除全天 | 選定日期的所有節次＋未分節，可限定座號 | `clearSeatDay(opId, 日期, 座號?)`：比對 A（＋B） |
| 依日期區間刪除 | 區間內所有節次（確認視窗寫明「包含全部節次」） | 逐日排入 `clearSeatDay` |
| 清除全部 | 全部 | `clearSeatAllV2(opId)` |

**舊入口相容（給部署當下還開著的舊頁面）：**
- 舊 `clearSeatRecords(date, seat)`：只清**未分節**（H 空白）的列，不會刪到分節資料。
- 舊 `clearSeatAll()`：**直接拋錯**「頁面版本太舊，請重新整理」（同舊匯入）。
- 舊 `setSeatCount(只有日期, …)`：寫到未分節（H 空白），不受影響。

### 3.4 匯入（區分合併／取代）

> 修正一個**現有 bug**：目前「合併匯入」只合併「本機＋備份檔」，再整份覆蓋試算表，試算表裡有但本機沒有的紀錄會消失。

- **合併匯入**：不整份覆蓋。本機合併後，把「合併後比原本大」的每一格排成一般 `count` 工作送出（沿用絕對值逐格寫入），試算表其他資料不動。
- **取代匯入**（使用者明確選「覆蓋」才走）：`importSeatRecordsV2(opId, rows)`：
  1. 前端先呼叫 `getSeatRowsRaw()` 下載一份**雲端快照**（A～H 原始列，JSON 檔，檔名含「_匯入前雲端」），確認下載後才送出匯入。
  2. 後端在文件鎖內驗證每一列：日期是真實日期、時段鍵合法（含 `#?原文` 未知節次）、座號與次數是安全正整數、項目代碼非空、(時段鍵＋座號＋項目代碼) 不重複。任一列不合格就整批拒絕，不動試算表。
  3. **先覆寫、後截尾**：從第 2 列開始用新資料覆寫，再刪掉新資料以外多出來的舊列；不經過「整張清空」的狀態。
  4. 寫完讀回，以「(時段鍵＋座號＋項目代碼) → 次數」逐筆比對；不一致回報錯誤，前端提示用雲端快照與本機備份還原。
- 舊 `importSeatRecords(rows)`：直接拋錯「頁面版本太舊，請重新整理」。
- 匯入的資料（payload）連同工作一起存進佇列；存不進去（容量不足）就不執行並提示。

### 3.5 破壞性操作與佇列同序

- 清除、取代匯入**排進同一條同步佇列**（工作類型：`count`／`clearSlot`／`clearDay`／`clearAll`／`import`），由同一個單工鎖依序送出。
- **保存順序**：先把新工作寫進佇列並確認寫入成功，再改本機紀錄；佇列寫不進去就整個操作取消並提示（localStorage 是同步寫入，兩步在同一次執行內完成，不會被關頁打斷）。
- 排入清除或取代匯入時，移除佇列裡**範圍完全相同**的待送 `count` 工作：清除本節＝同時段（有指定座號就再加座號條件）；清除全天＝同日期所有時段（＋座號）；清除全部、取代匯入＝全部 `count`。**正在送出中的那一筆不移除**（無法撤回，由後續的清除工作覆蓋其結果）。
- 舊佇列中沒有 `type`／`id` 的工作視為 `count`，載入時補上 `id`。

### 3.6 本機合併、拉取遮蔽與統計

- 拉取時合併照舊（逐格取較大值），鍵是時段鍵。
- **拉取遮蔽**：
  - 佇列裡還有待送的清除／取代匯入時，拉回來的資料中**落在那些範圍內的格子一律忽略**（以本機為準），等清除完成後的下一次拉取再合併。
  - 每次發出拉取時記下「破壞性操作序號」；回應到達時若序號已變（期間排入過清除或匯入），**整個回應丟掉**，重新拉一次。
- 所有「日期」計算（日期列、近 N 天、每週統計、區間刪除）一律經 `slotDate()`；**天數按不同日期去重**，人數按座號去重；區間篩選同時檢查起日與迄日。

### 3.7 工作 ID 與後端去重

- 每個佇列工作都有唯一 `id`（時間＋亂數）。送出成功後**依 id 移除**，不再比對 date／seat／key／count（避免不同清除工作被誤認為同一筆）。
- 清除與取代匯入帶 `opId`。後端在文件鎖內查「最近處理過的 opId」（存 DocumentProperties，保留最近 200 筆）；**重複的 opId 直接回覆上次結果、不再執行**。所以重新整理後重送同一個清除，不會再刪一次。
- `count` 是絕對值，本來重送就安全，不另做去重。
- **錯誤分類**：後端驗證失敗（格式、版本太舊）拋出以「永久：」開頭的錯誤 → 前端暫停佇列、跳出提示，不自動重試；其他錯誤（網路、逾時、鎖等待）照舊 15 秒重試。

## 4. 畫面

### 4.1 登記

```
[ 週一 10/6 ] … [ 週五 10/10 ]                               ← 日期列（原有）
[早自習][第1節][第2節][●第3節 ²][第4節][午休][第5節][第6節][第7節] [未分節 ⁵] [全天]
 第 3 節（10:30–11:10）・自動            ← 或「手動・回到自動」
```

- 點座位登記到「選定日期＋選定節次」。節次按鈕右上小數字＝該節總次數。
- **「未分節」按鈕只在該日期有舊紀錄時出現**，可查看、扣減、清除，也可補登（就是一個時段）。
- **「全天」只供觀看**：座位顯示全天加總；點座位、復原、清除本節都停用並提示「請先選一節」；「清除全天」可用。
- **彈窗與復原記住時段**：開彈窗時記下當下時段鍵，彈窗內所有加減都寫到這個時段，期間自動切節暫停；復原堆疊每筆存 `{ 時段鍵, 座號, 項目 }`，復原時扣回原本那一節（畫面不在那一節時提示「已復原第 2 節的一筆」）。

### 4.2 統計

- 範圍按鈕保留（今日／近 7 天／近 30 天／全部／每週統計），新增「自訂」（起～迄）。
- 節次篩選：預設「全部節次」，另有「本節」「自訂」；選自訂才展開節次複選（含「未分節」）。按鈕旁持續顯示篩選摘要，例如「近 7 天・第 3 節」。
- **統計表、複製報告、CSV 都套用同一組篩選**；右側摘要（今日／本週／全部／本節）是獨立的。
- **CSV 定義**：
  - 「匯出統計 CSV」＝現有格式（每人一列的彙總），開頭兩行註明「日期範圍」與「節次」。
  - 新增「匯出逐節明細 CSV」＝一筆一列：日期、節次、座號、姓名、項目、次數。

## 5. 驗收

功能：
- 第 3 節登記 2 次 → 第 4 節是 0 → 回第 3 節是 2；全天顯示 2，全天模式點座位／復原不會寫入。
- 第 2 節登記後切到第 3 節按復原 → 扣回第 2 節，第 3 節不變。
- 彈窗開著時跨過節次時間 → 彈窗內的加減仍寫到原節次。
- 08:45 開啟→第 1 節；10:15→第 2 節；手動點第 4 節後時間到第 5 節仍停在第 4 節；按「回到自動」跳回現在節次。
- 同日第 3、4 節與未分節都有資料 → 清除本節（第 3 節）只刪第 3 節；清除全天三者都刪。
- 舊資料在「未分節」看得到、可扣減；全天加總含舊資料。
- 統計：「近 7 天＋第 3 節」只算第 3 節；同一天兩節只算 1 天；每週統計不因兩節而分成兩週。
- CSV 兩種都正確；JSON 備份→還原後時段鍵不變。

408 同步（Node 模擬試算表＋瀏覽器內模擬 google.script.run）：
- H 欄寫入、舊列（H 空白）讀回未分節、H 為對照表外文字保留為獨立時段。
- 重送同一筆不重複；清除與 count 工作同序，清除後舊次數不會寫回。
- 匯入 V2：資料列變少時不殘留舊列與舊 H；舊 `importSeatRecords` 會拋錯。
- **舊頁面＋新後端**：只送日期的 `setSeatCount` 寫到未分節；舊 `clearSeatRecords` 只清未分節。
- **拉取遮蔽**：清除全天排入後、送出前收到舊的拉取回應 → 不復活；重新整理後佇列 `clearDay → count(1)`、雲端舊值 2 → 最後本機與雲端都是 1。
- **重複 opId**：同一清除送兩次 → 第二次不執行（之後登記的資料不會被刪）。
- **合併匯入**：雲端獨有的紀錄保留；只送出變大的格子。
- **取代匯入**：資料變少時不殘留舊列與舊 H；中途失敗（模擬逾時）時試算表沒有出現全空；不合格的列整批拒絕；寫後比對錯誤會回報；未知節次 `#?原文` 可還原回同樣的 H 文字。
- **舊入口**：`importSeatRecords`、`clearSeatAll` 拋錯；`clearSeatRecords` 只清未分節。
- **指定座號清除**：同節其他學生的待送工作不被移除。
- **回復模式**（`SEAT_PERIOD_UI=false`）：只讀寫未分節，分節資料看得到但不被改動。
- 兩版既有測試全部通過。

## 6. 部署與回復

GAS 版的前端頁面與後端在**同一次部署**一起更新，所以不會出現「新頁面配舊後端」；需要處理的是**部署當下還開著的舊頁面**與**本機佇列裡的舊工作**，已由 §3.3（舊清除只清未分節）、§3.4（舊匯入拋錯）、§3.5（舊工作視為 count，只寫未分節）處理。

部署前（**每次**動到秩序登記的部署都做）：
1. 用 Sheets API **唯讀**匯出「上課表現紀錄」**A～H** 全部列到本機（不在試算表新增任何分頁），打開確認可讀、列數與試算表相同。
2. GAS 版按「匯出 JSON」下載本機紀錄；JSON 一併包含**待送佇列**與檢查項目、座位表設定。
3. Node 模擬與瀏覽器測試全過。

部署後：
1. 開 GAS 網址，在**第 1 節**點一位學生一次 → 試算表多一列且 H＝「第1節」、A～G 格式不變 → 扣回 0，該列刪除。
2. 請使用者把教室大屏與筆電都重新整理一次（讓舊頁面換成新版）。

回復：
- **不可退回舊 7 欄後端**：舊 `setSeatCount` 只比 A＋B＋G，會把不同節次的列當成同一列覆寫。
- 回復＝部署「新後端＋關掉分節畫面」（`SEAT_PERIOD_UI=false`）：畫面回到舊版樣子，**只讀寫「未分節」時段**（座位顯示未分節次數，點了就是未分節 +1），分節資料保留在試算表與本機、統計仍看得到，但不會被改動。不用全天加總當寫入值。

## 7. 不做的事

- 不依課表自動標出科目名稱。
- 不自動把舊紀錄分配到節次。
- 不做畫面上的作息編輯（改常數）。
- 不另建試算表副本做隔離測試（見附錄 A B-中）。
- 不做跨裝置刪除傳播（既有決策：本機優先保留；§3.6 的遮蔽只處理同一台裝置的先後順序）。
