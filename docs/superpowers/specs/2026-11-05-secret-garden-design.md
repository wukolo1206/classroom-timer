# 班級祕密花園（已由使用者確認方向）

- 平面自然插畫、奶油色工具列；角色直接使用 points/avatars.js 的 SVG，座號區分同款角色。
- garden.html 是可取得麥克風的獨立頁面。408／全校版音量計新增入口，保留原音量計。
- 自習／輕聲討論、1～120 分鐘倒數、講解暫停、全螢幕。倒數只在啟動麥克風成功後運作；隱藏頁面自動暫停，回來須手動繼續。
- 首位夥伴在合宜音量累積 15 秒後出現，其餘依剩餘活動時間與人數分配；暫停成長不移除已出現角色，短暫聲響容忍 3 秒，恢復需 2 秒低於門檻。無訊號不累積。
- 每人只出現一次，跨場輪替第一位。結束時本機收藏成果摘要，可查看最近 12 次；不改點數。
- 開始前及「更新夥伴」讀目前角色。GAS 使用新的唯讀 getGardenRoster，不呼叫會匯入分數的 getPointBundle；角色由設定與未復原的 avatar:N 事件推導。只傳座號／頭像索引，不傳姓名／分數。
- GAS 與 GitHub 不同來源，使用 window.open + 限來源、視窗、隨機通道的 postMessage 往返。GAS 留在原視窗供更新；中斷時保留已載入角色並明示失敗，不假稱最新。
- 本機入口讀同來源本機計分；全校版讀自己的名冊，無名冊可用示範模式且清楚標示。不同來源不互相冒充。
- 不部署／不 push，先完成可審閱版本、隔離測試與畫面驗證；正式上線仍需最後核可。
