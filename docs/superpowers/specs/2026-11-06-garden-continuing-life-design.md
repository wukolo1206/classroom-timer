# 八階段後持續變化的花園日常

日期：2026-11-06。狀態：老師已核定並要求實作；v1.28已依本規格完成並發布，49項瀏覽器回歸／純模型與正式31位唯讀驗證通過，詳見handoff.md。
正式基準：v1.27／GAS @65，最新來源C:/worktrees/group-points-ledger。

## 老師的回饋與目標

老師已在課堂實測，效果很好；希望關卡後續仍有變化，加入噴水池、雕像、更多手持物與球類、種花與澆水。已選定「保留前8階段，完成後持續變化」。延續原可愛平面插畫與學生目前頭像，減少連續重複，同時保持留白。

## 方案比較與選擇

- 選定：8階段完成一幅畫，之後持續解鎖花園日常。已完成景色不因退場丟失，後續每段合宜音量仍有可見回饋。
- 棄選：固定增加到24關。仍會到終點，素材逐關堆疊也容易太擠。
- 棄選：每場一開始便完全隨機。少了前8階段共同完成畫作的節奏。

「持續」指可長時間輪替有限素材與組合，不宣稱無限產生全新插畫。首批建立可擴充內容目錄，未來可增加新主景、動作與配色。

## 合宜音量與解鎖節奏

1. 前8階段、隨機迎人、出場／超標退場／升級秒數均保留。
2. 月光完成且全員在場後，每一段升級時間（沿用設定，預設30秒）獲得1次「花園新發現」，取代只有祝福數字增加的單調回饋。
3. 第1次新發現一定出現噴水池，並解鎖籃球活動；第2至8次依序解鎖另外7種新活動。之後仍持續輪替主景、活動與道具配色，不增加新物件總數。
4. 每次新發現安排最多2位夥伴展示本次活動，其他人照常做各自的小活動。展示對象隨機，不與座號、分數或誰發出聲音連動；一輪盡量讓每人都有機會。
5. 第1、5、9、13……次新發現切換主景，其餘次數以角色活動與道具變化回饋。背景主景在約6秒內柔和替換；不用遮住全畫面的慶祝動畫。
6. 短暫超標立即凍結倒數與全部動態；真的退場才清除未完成的新發現倒數，已獲得的次數／主景／活動解鎖保留。全員回來後重新累積一段時間。
7. 老師暫停、無訊號、離頁與活動結束，持續遵守目前共同停止狀態；新場重設新發現及解鎖，重新從8階段開始。

## 首批6種主景

| 主景 | 演出 |
|---|---|
| 木橋池塘 | 保留目前完成畫的主景，作為初始與後續輪替選項 |
| 小噴水池 | 淺盆搭配最多3道短水柱，柔和循環，不加音效 |
| 兔子石像 | 小台座、可愛兔子輪廓與花環，沒有閃爍或滿天裝飾 |
| 小鳥飲水台 | 淺水盤及最多2隻背景小鳥；它們取代部分動態點綴，不無限追加 |
| 花藤拱門 | 一座低矮拱門與有限花朵，保留天空與人物空間 |
| 小風車 | 一座花園風車，小幅緩轉；不增建房屋或整排建築 |

主景使用右側預留景觀區，同時只顯示1種完整主景組合。替換時對應調整該區水面／基座；角色腳點不改變，也不把人排入該區。輪替使用洗牌袋，一輪看過其他選項後才重複，不連續兩次同款。切換時至多2個主景圖層短暫交叉淡入淡出，結束後移除舊圖層。

月光花園仍是完成背景，本次不額外實作日夜循環或四季，以免同時改變太多內容。

## 首批8種新活動

| 解鎖次序 | 新活動 | 小範圍動作 |
|---|---|---|
| 1 | 籃球 | 原地輕拍球；空間不足則抱球休息 |
| 2 | 足球 | 腳邊輕推、停球，不跨格追球 |
| 3 | 排球 | 原地抱球或小幅向上拋接 |
| 4 | 網球 | 球拍與球，原地輕托球，不大幅揮拍 |
| 5 | 棒球 | 手套接球、抱球，小幅動作 |
| 6 | 羽球 | 羽球拍與羽球，小幅托球 |
| 7 | 播種 | 種子袋、小鏟與小花盆，撒下種子 |
| 8 | 移苗種花 | 小花苗移入花盆、拍平土壤 |

保留看花、野餐、澆水、追蝴蝶、閱讀及散步。既有澆水新增不同配色水壺；花盆、球與球拍各有少量固定配色。活動目錄抽取以避免剛做完又抽到相同活動；減少動畫時保留靜態姿勢與道具。

動作須明確可辨認，不能只換道具卻沿用完全相同的身體動作。所有道具與球停留在各自安全範圍；不跨越別人、不蓋座號、不滾到音量尺／字幕。小螢幕允許以抱球／持物姿勢取代大動作。

## 畫面與效能上限

- 主景1組，過渡短暫最多2組；完成過渡後DOM不累積。
- 每位1種活動／1套道具；同時散步最多3位、新解鎖展示最多2位、追蝶最多2位。
- 普通植物最多48株、花圃4處各3朵，晚霞後停止新增株數；種花活動用手上小花盆，不持續往場景堆花。
- 蝴蝶最多3隻背景＋2隻角色追蝶；星12、螢火5不因新發現增加。小鳥主景中的小鳥最多2隻。
- 每次主要只變主景或2位展示夥伴，其他活動平緩輪替，避免全班一起劇烈跳動。
- 沿用SVG／CSS向量插畫及可暫停漸變，不新增錄音、聲音上傳、AI即時生成或網路依賴。

## 資料、活動紀錄與PNG

- 保留前8階段資料；新增新發現次數、當次主景、解鎖活動與最後摘要。舊4／8階段紀錄照原方案顯示，不倒推新發現次數。
- 以新紀錄schema明確辨識此次擴充；新紀錄保留8階段名稱及當次主景名稱，活動紀錄最多12筆。
- PNG保存包含當下主景、球類／園藝道具及實際姿勢；預設無HUD、可選座號。結束後原圖保留於記憶體供重試，不把PNG塞進localStorage。
- 不更改學生頭像原圖、頭像配對、點數、GAS唯讀名冊接口或工作表。

## 模組邊界

- 規則：8階段完成後的新發現計時／次數與主景洗牌袋；使用可注入亂數，便於重現。
- 內容：主景與活動目錄，宣告解鎖順序、名稱、道具／動作、配色及上限。
- 生活：接收已解鎖活動與最多2位展示任務，保留以座號維護角色狀態的方式。
- 呈現：主景替換、動作與新發現文字；共同有效狀態凍結動畫和漸變。
- 保存：版本化摘要及同一座標矩陣的PNG；保留現有失敗重試流程。

## 驗收

1. 前8階段與原15／8／30秒規則不退化；第1次新發現看得到噴水池與籃球，之後各次有明確回饋。
2. 8種新活動依序解鎖，已解鎖後能繼續輪替；主景每4次更換，一輪不重複且不同輪邊界不連續同款。
3. 每一個主景／新活動都能暫停、超標凍結、無訊號停止、恢復，退場不丟已完成內容。
4. 長時間模擬至少200次新發現，DOM與物件數有上限，沒有負計時／無限堆星／植物或配額膨脹。
5. 1366／1024／640／390及100人配置：人物落地、道具與球不碰鄰居、HUD、座號與字幕；主景不改腳點。
6. 每種新主景及道具的PNG可下載，左右朝向／旋轉幾何正確；全螢幕、結束凍結、存圖失敗重試仍正常。
7. 舊4階段、原8階段、新紀錄及本機儲存已滿情境；原點數／設定不變。發布後用正式唯讀入口核對目前頭像，不試寫學生資料。
8. 真實教室與iPad的效果需另行記錄，不能用瀏覽器模擬當成實機通過。
