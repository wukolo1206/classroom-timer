# SH150 學校 Google 表單填報 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `executing-plans` 逐項執行本計畫；本交接不要求多代理。Steps use checkbox (`- [ ]`) syntax for tracking。

**Goal:** 在全校版 SH150 提供每週彙整、可更換的 Google 表單預填設定，以及複製填報資料備援，讓老師核對後補照片並自行提交。

**Architecture:** 維持 `universal.html` 單檔與同源 SH150 `srcdoc` 架構。框架提供所選週次的唯讀資料快照，外層負責純計算、設定、核對視窗、Google 表單連結與複製；更換學校表單只修改新增的 `ctu_` 設定，不碰歷史紀錄。

**Tech Stack:** 原生 JavaScript、既有 HTML/CSS/Tailwind CDN、localStorage、URL/URLSearchParams、Python Playwright；不增加後端、GAS、OAuth 憑證或正式資料庫。

**計畫版本：** 1.0，2026-10-07。使用者已同意「可換預填範本＋複製備援＋老師確認提交」方向。本檔是 Claude Code 執行交接，Codex 本次只寫文件。

## 3. 老師操作流程與畫面文案

在 SH150 工具列新增「📤 填報學校本週資料」，放在列印附近，不干擾清空按鈕。第一次切換 SH150 仍採原本 lazy load。

```text
SH150 選擇第幾週
  → 點「填報學校本週資料」
  → 核對班級、導師、所選週日期、每日明細與整週合計
  → [開啟預填表單] 或 [複製填報資料] 或 [學校表單設定]
  → 老師在 Google 表單核對數字、補照片、按提交
```

### 預覽視窗

- 顯示班級、導師、學期標籤、週次、週一～週五完整日期、填報當下日期時間（Asia/Taipei）。
- 顯示五天的學生跑步合計、跳繩下數、跳繩換算圈數，以及導師原始跑步圈數。
- 顯示「學生填報圈數」及「導師填報圈數（尚未乘 2）」兩個明確數字。
- 顯示計算說明：「跳繩依每天全班加總，每 200 下換算 1 圈；五天再相加。學校後台會把導師圈數乘 2。」
- 顯示「不含體育課；請確認登記資料符合學校規定。」程式無法從既有紀錄自動排除體育課。
- 顯示提醒：「請在表單補上 1～2 張活動照片，並自行按提交。開啟表單不代表已繳交。」
- 老師改週、修改紀錄、修改設定後，下一次預覽重新取快照。視窗打開期間若框架週次／資料變動，按開啟或複製前再次比對快照，必要時更新並請核對，不送舊預覽數字。
- 不列學生個別姓名，不把名冊寫入外部 URL。可顯示目前名冊外座號的「有紀錄座號」及警告，使用座號即可。
- 375px 可操作，對話框有最大高度及內部捲動；按鈕可換行。所有老師輸入內容以 `textContent` 渲染。

### 導師跳繩

既有 `teacherRuns` 只記導師跑步。本批不改運動登記結構；預覽可提供選填「導師額外換算圈數」，預設 0，只接受非負整數，由老師自行換算導師跳繩或其他學校認可項目。

- 文案：「若導師另有跳繩，請填尚未乘 2 的換算圈數；沒有則填 0。」
- `teacherTotal = teacherRunTotal + teacherExtraLaps`，不乘 2。
- 額外圈數只在本次預覽使用；換週或關閉視窗即歸零，不永久新增資料 key、不覆蓋導師跑步紀錄。
- 本機列印依舊有跑步紀錄計算；預覽若有額外圈數，明示「本次額外填報，不含於原 SH150 列印總數」。

固定輸出下列形狀，實際值由快照取得：

```text
SH150 每週填報資料
班級：101
導師：示範老師
學期：115-1，第 6 週
運動期間：2026-10-05～2026-10-09
填報時間：2026-10-07 13:05（臺灣時間）

  跑步：3 圈；跳繩：350 下；每日換算合計：1 圈

  跑步：3 圈；本次額外換算：0 圈
```

## 4. 圈數計算契約

### 資料來源與橋接

框架新增唯讀 `window.ctuGetSh150ReportSnapshot()`，回傳 `{ week: currentWeek, records, teacherRuns, rosterCount, dates }` 的深拷貝。`rosterCount` 為實際框架名冊人數；`dates` 是五筆 `{ day: 1至5, ymd: YYYY-MM-DD }`，以框架初始化時的 `SEMESTER_START_MONDAY` 加 `(week - 1) * 7 + (day - 1)` 天產生，包含完整年份，不從畫面月／日字串猜年份。外層不直接讀框架的 `let` 變數，不抓畫面總計字串當資料。

點框架填報按鈕時呼叫外層 `window.ctuOpenSchoolReport()`；外層從 `#sh150-frame.contentWindow` 取得快照。外層尚未就緒或框架未載入時給提示，不拋未處理例外、不觸發重新載入。框架不增加任何非 `ctu_` 儲存。

取當前框架的記憶體資料可避免「儲存容量滿」時從 localStorage 讀到舊資料。若快照與儲存資料不一致，預覽提示「本次依目前畫面資料計算；請先備份，確認紀錄已儲存」，不假裝已存檔。比較只讀相關當週資料，不變更任何 key。

### 純函式介面

外層將以下純函式放在具名 `window.ctuSchoolForm` 命名空間，便於測試與避免全域撞名。這些是新功能介面，不變更原計分函式：

```text
summarizeWeek(snapshot, rosterCount, teacherExtraLaps)
  → { week, dates, daily, studentRunTotal, studentJumpTotal,
      studentJumpLaps, studentTotal, teacherRunTotal, teacherExtraLaps,
      teacherTotal, recordedOutOfRosterSeats, hasRecords, warnings }
validateConfig(config)
  → { valid, errors, warnings, normalized }
parsePrefillTemplate(url)
  → { formUrl, formId, entries, errors }
buildPrefillUrl(config, report, reportedAtTaipei)
  → { url, omittedFields, errors }
buildReportText(report, classInfo, reportedAtTaipei)
  → string
```

圈數規則：

1. 對每天 d=1～5 計算 `studentRun[d] = sum(run)`、`studentJump[d] = sum(jump)`。
2. `studentJumpLaps[d] = floor(studentJump[d] / 200)`。一定先全班加總再取整，不是逐人取整。
3. `studentTotal = sum(studentRun[d] + studentJumpLaps[d])`。不是把五天跳繩總下數一次取整。
4. `teacherRunTotal = sum(teacherRuns[d])`，`teacherTotal = teacherRunTotal + teacherExtraLaps`。學校後台加倍，不能再取原 `grandTotal` 當學生欄位。
5. 從該週所有有效座號紀錄計算，包括現行名冊外座號，避免老師縮減人數時舊運動消失。名冊外座號須列警告並要求老師核對後才開啟預填；不刪掉原紀錄。
6. 不依目前名冊長度或列印最低 35 列作為統計上限。有效座號為正整數，星期 1～5；其他鍵不計入並列警告。
7. 數值缺欄位視為 0；合法數字字串可以讀取。非數字、NaN、Infinity、負數與非整數不靜默改為 0，彙整標資料有誤並停用自動帶入，供老師先處理。合法超過 UI 單筆上限的歷史整數不截斷，顯示核對警告。
8. 全週沒有紀錄：顯示「目前沒有本週紀錄」，數字可為 0；開啟表單前要求明確核對，不把缺資料誤當已完成登記。

核對例：週一兩人跑步 1、2 圈、跳繩 150、100 下；週二跳繩 100 下；導師週一 2 圈、週二 1 圈。學生為 `3 + floor(250/200) + floor(100/200) = 4` 圈；導師送 3；含導師加倍的原合計應為 10。整週跳繩總下數 350 只供說明，不再另外加一次。

### 設定畫面

- 一般老師看到學校表單網址、目前核對狀態、最後設定時間、照片與登入提醒。
- 「更換學校表單」可貼完整作答者網址或官方預填連結，先解析到草稿，顯示目的表單與變更差異，儲存時才更新本功能 key。
- 進階區顯示語意欄位對應表，讓維護者從範本解析出的 entry 選定導師、班級、學生圈數、導師圈數；不能依 query 順序自動猜語意。
- 提供獨立的「匯出填報設定」與「匯入填報設定」，方便維護者將同一份對應交給其他老師。設定包只含目的表單、欄位對應、選項與格式，不含班級名冊、登入資料或運動紀錄。不能與完整資料還原混用。
- 匯出的設定 schema 保留，移除個人班級值與原預填樣本內容。匯入只寫 `ctu_school_form_config`，全部驗證後才套用；匯入設定標為需重新核對。
- 「重設學校表單設定」只重設本功能設定，不能调用 `removeAllCtuKeys`、`clearAll` 或整份還原。
- 修改表單網址、entry、日期格式、班級選項時將核對狀態改為 unverified，`revision + 1`；取消草稿不變更已存設定。
- 換表單時不提供修改跳繩除數或導師倍數選項，避免用表單設定偷偷改計分。若學校計算規則改變，需另開規格與驗收，複製備援仍可用。

### URL 與範本驗證

1. 僅接受 HTTPS、hostname 精確為 `docs.google.com`，路徑為 `/forms/d/e/{formId}/viewform` 或 `/forms/u/{數字}/d/e/{formId}/viewform`，後者正規化成前者。不接受編輯、`formResponse`、帳號切換、短連結、localhost、第三方或含帳密的 URL。
2. `forms.gle` 短連結只提示「請開啟後複製完整作答者網址」，不在程式中 fetch 追蹤轉址。網址與 query 合理上限 16 KiB，設定 JSON 最大 64 KiB。
3. entry 綁定只能是合法的 `entry.{正整數}`；日期特殊綁定只允許已確認的該 entry 組件參數，不能混入提交控制參數。
4. 四個語意欄位均需存在、互不重複。日期組件與其他語意不可衝突。接受原表單 entry 不接受任意 query 直接拼入。
5. 解析預填範本時保留 entry 名稱供選取，值只用於暫時的示範辨識，儲存前移除；不保留照片識別或未知預填回答。
6. 輸出連結由正規化的 formUrl 加 `usp=pp_url` 及已允許的動態 entry 建立；不保留範本的 `authuser`、`pli`、token、登入選擇等參數。
7. 用 `URLSearchParams.set` 編碼中文、空格、`&`、`+`、`#`，禁止手動拼接未編碼答案。不把範本當 HTML、程式或 `eval` 處理。
8. 班級值不在選項內則停用自動帶入，允許複製及開啟空白表單。例 `4XX` 不匹配時請老師先改正班級設定；不要偷偷改現有設定。
9. 導師未設定或仍是 `OOO 老師`，要求核對真實導師姓名再預填；不能套用目前登入帳號推測姓名。

### 取得預填範本的方法

提供給學校承辦的說明：在表單編輯畫面選「更多 → 預先填寫表單」，填示範導師、合法班級選項、學生 123456 圈、導師 654321 圈，以及示範日期時間，取得連結。取得連結不是提交正式回應，不上傳學生照片。

老師在工具貼上這份連結後，從示範答案確認語意對應；班級值用示範合法選項，不用假造班級。日期時間依該正式產生的參數布局設定，12／24 小時、午夜與跨年必須實測。

### 改表單的行為表

| 變更 | 本功能處理 |
|---|---|
| 只改說明、標題、順序，原 entry 留著 | 原對應可能仍可用；人工核對 |
| 題目刪除重建 | 更新 entry；舊核對狀態失效 |
| 換全新表單 | 更新 formUrl、重新建立對應，不搬動運動紀錄 |
| 增加必填欄位 | 老師在表單補填；既有四欄維持對應，不承諾自動發現新增題 |
| 改班級選項 | 更新 classOptions；不匹配時停止帶入 |
| 改計算規則或學期歸屬 | 另行確認規則，不僅是改網址；保留原紀錄 |
| 停收、改登入權限、預填遭忽略 | 手動複製備援；學校端處理權限／停收 |

## 6. 開啟、登入、成功狀態的邊界

- 使用老師點擊事件直接產生並開啟新分頁，避免先 await 導致彈窗被擋。`window.open(url, '_blank', 'noopener,noreferrer')` 或等效安全 `<a>`。
- 若以 `noopener` 開啟，不能僅憑回傳 null 判定彈窗被擋；始終提供「若未開啟，點此再次開啟」的可見安全連結。
- 外部表單單独分頁開啟，不嵌進工具 iframe，不從 GitHub Pages 直接 fetch 表單，不直接 POST `formResponse`。
- 學校帳號登入、照片與最終提交均留在 Google 原頁面。工具不接收或保存帳號授權；不繞過網域限制。
- 因跨網域及沒有回應查詢介面，工具無法知道學校實際收到。UI 只可顯示「已產生連結」「請於學校表單完成提交」，不顯示「已繳交」「同步成功」。本批不新增已送出紀錄或後台成功偵測。
- URL 會含導師姓名、班級與彙整圈數，可出現在瀏覽器歷史。只有老師主動按開啟才送出，不自動載入、不加 analytics；不含學生姓名與照片。不要把真實預填 URL 寫入測試報告或公開提交。
- 複製與彙整可在離線使用；表單填報與下載新版仍需要網路。離線不改本機資料也不自動排程送出。
