# 小組討論共用簡報版面

使用者已同意「共用簡報版面、編輯以視窗開啟」，並要求修改後發布兩版。

1. 修改前備份 index.html、universal.html、gas/index.html 與既有測試。
2. 先驗證進入討論預設就是簡報版面；任務未儲存不影響顯示；專注切換不改字級、欄寬、計時、分數或輪抽。
3. 將簡報樣式綁定討論分頁，專注顯示僅收起標題、導覽與編輯入口。保留小螢幕、長任務捲動及單行分頁。
4. 保留原任務編輯視窗；新增討論設定視窗，移入原組數、組名、加分項目、範本與分數重設入口，沿用原事件與保存方式。
5. root 同步 gas；執行小組回歸、分頁切換、JS 語法、內嵌工具及鏡像一致性，檢查兩版桌面／手機截圖。
6. 原始碼備份後沿用既有 GAS deploymentId 發布；全校版更新版本並提交推送。核對公開 HTML 與提交，使用隔離瀏覽器驗證。正式試算表不作測試。

新增 class 僅負責顯示；不增加雲端欄位、localStorage schema 或分數／輪抽轉換。使用者資料維持原本保存邊界。
