# 花園生活動作與漸進花朵

使用者要求既有頭像更生動：走動、看花、野餐等不同活動，花朵慢慢變多。沿用已核可的花園、現有頭像與音量規則，不修改頭像原圖／正式配對／GAS／點數。

設計：每位夥伴有自己的活動狀態與錯開的時間；小範圍散步後進入看花、野餐、澆水、追蝴蝶或閱讀。每人有保留的安全區域，最多約每8人一位同時走動；夥伴更新頭像不重設活動，離場即移除該角色狀態，新場全部重設。超標、老師暫停、缺少音訊、離頁與結束都不推進動作；減少動畫偏好不走動。

花朵根據同一合宜音量時間，每6秒多一株，經過嫩芽→花苞→綻放；更新現有植物而非重建整片花園，上限72株維持裝置效能。花朵在草地／花圃附近漸增，位於角色下層，不遮擋座號／音量尺。
