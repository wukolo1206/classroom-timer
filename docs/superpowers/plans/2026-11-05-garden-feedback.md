# 花園回饋修訂施工清單

使用者於本機預覽後指定：隨機夥伴、可見分貝器與目標範圍、固定秒數的夥伴倒數、超標立即暫停與持續超標減少夥伴、角色動作、直接偵測及全員到齊後升級。

規則：預設直接偵測無活動期限；可選活動倒數。合宜音量累積15秒迎來一位（可調1～300秒），超標立即凍結小倒數；連續超標8秒（可調3～60秒）讓一位休息，持續超標每隔同樣秒數再減一位。恢復合宜音量後接著倒數，離開的夥伴可以再回來。每輪從未在場的名單隨機抽取，不重複顯示同一位。

全員在場後每累積30秒（可調5～300秒）依序解鎖盛開、蝴蝶、星光，再繼續累積星光祝福。超標暫停此倒數；減少夥伴時清除此階段尚未完成的進度，已解鎖成果保留，先迎回缺席夥伴再繼續升級。角色在自己的小範圍搖擺、跳躍、轉身與飄動，超標或老師暫停則休息，減少動畫偏好仍有效。
