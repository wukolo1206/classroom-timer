# 頭貼抽獎與收藏設計（草案，待老師核定）

日期：2026-11-18｜範圍：408 版（index.html／gas），不動 universal.html、sh150-tracker

## 一、老師已決定的規則
1. 學生**不花點數**抽頭貼；抽到就「擁有」，重複抽到允許（沒有新增）。
2. 抽獎券來源兩種：**國語測驗達標**（就是會加點的那一次）自動給一張——**原本的加點照舊，抽券是額外多的一個活動，不取代加點**；**老師手動發**（單人或全班）。
3. 學生拿到券後，自己在**教室電腦／大屏**選座號按鈕抽，不做登入／PIN。
4. 換成**自己已擁有**的頭貼不花點數。
5. 「花 5 點換角色」先拿掉；之後可再加「幾點才能換」的設定（預留 `avatarCost` 欄位）。
6. 獎池＝**老師目前開放的系列**；頭貼分系列，之後新增的系列也套同一機制。
7. 素材：`台灣點心精靈娃娃/` 14 隻 PNG，縮到約 128～160px 嵌入，維持單檔離線。

## 二、資料設計（不改「班級集點紀錄」11 欄表頭）
全部沿用現有集點事件（固定 ID 去重、離線佇列、可復原），新增三種 itemId，`delta` 一律 0：

| itemId | 意義 | 備註 |
|---|---|---|
| `ticket:grant` | 老師發券 | 備註欄寫張數；全班＝每人一筆 |
| `draw:N` | 抽到頭貼 N | **後端在鎖內抽籤**，結果寫進事件，重整或重送不能重抽 |
| `equip:N` | 換上已擁有的 N | 後端驗證已擁有 |

- 測驗券：不另寫事件，直接由「測驗匯入且 delta>0」的紀錄推導（編號已去重），只計 `TICKET_QUIZ_SINCE`（預設 2026-11-18）之後的，避免舊成績一次發出一大堆券。
- 擁有清單 ＝ 預設頭貼（`n%8`）＋ 舊的 `avatar:N` 付費事件 ＋ 未被復原的 `draw:N`。**已經在用的角色自動算擁有，不用重買。**
- 券數 ＝ 測驗券 ＋ 老師發券 − `draw`（未復原）。
- 目前角色 ＝ 最後一筆未復原的 `equip:N`／`avatar:N`／`draw:N`（抽到不會自動換上，需要自己按換）。
- 頭貼系列：`points/avatars.js` 新增系列表（`經典夥伴` 0–23、`台灣點心精靈` 24–37）；開放系列存 `pointSettings.openSeries`。
- 這會**推翻 DECISIONS 2026-10-14「換角色＝扣點事件」**；要在 DECISIONS 用刪除線標註，並說明舊事件仍有效。

## 三、介面
- 集點頁每位學生卡片顯示 🎟 券數；點進去有「抽頭貼」「我的圖鑑」。
- 抽頭貼：單一發光按鈕、動畫期間鎖操作、結果最後揭曉，沿用鷹架引擎的節奏；重複抽到顯示「已有了」。
- 圖鑑：依系列顯示已蒐集／總數，未擁有顯示剪影；點已擁有的即可更換。
- 設定頁：老師選「目前開放抽哪個系列」、發券（單人／全班）。

## 四、風險與待查
- 頭貼目前由 `svg(n)` 回傳 SVG 字串；PNG 要包成 `<img src="data:…">`，同一函式回傳即可，但**花園、拍賣系統**也讀頭貼，要逐一確認不破圖（拍賣改 `AVATAR_BASE_408` 並跑 `embed_avatars.py`）。
- `avatarIndex()` 目前限制 ≤23，要放寬；花園唯讀頭貼測試要更新。
- 測驗券依賴測驗匯入；匯入失敗時券會晚到，不會遺失。
- 沒有 PIN：學生可能幫別人按（教室大屏情境，已接受）；老師可用「復原」撤回抽獎。
